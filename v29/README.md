# v29 画像検出実験版

v25 / v28 と独立した検証用ページです。

## 現在の検出フロー
1. PP-OCRv5で画面全体から順位文字を検出
2. OCRで不足がある場合、OpenCV.jsで赤色領域を抽出
3. 赤色領域を含む小さな候補画像を作り、PP-OCRv5で再認識
4. 認識した順位の座標を既存のキャラクター選択UIへ渡す

## 重要な制約
- 現段階は「色・形状による候補領域抽出 + OCR」の実験です。学習済みAIモデルは使いません。
- まだ順位表示テンプレートを使った cv.matchTemplate / ORB の画像照合は実装していません。
- 赤色が隠れている、別色に変更されている、背景に赤色が多い場合は誤検出や未検出が起こり得ます。
- OpenCV.js CDNが利用できない場合は通常のPP-OCRv5経路にフォールバックします。
- v25 root と v28 は変更していません。

## テスト
実際のゲーム画面を複数キャラ・複数ステージで読み込み、1st〜4thの検出数とマーカー位置を比較してください。
